# ☁️ GCP Architecture Labs

Welcome to the Cloud Architecture laboratory. This space is dedicated to experimenting with Google Cloud Platform (GCP) services and implementing modern infrastructure solutions.

## 🎯 Goals
*   Hands-on study for the **Associate Cloud Engineer (ACE)** certification.
*   Implementing scalable CI/CD pipelines for **Angular 21** and **React 19** applications.
*   Infrastructure as Code (IaC) automation using Terraform.

## 🛠️ Tech Stack
*   **Cloud:** Google Cloud Platform (Compute Engine, GKE, Cloud Run, Artifact Registry).
*   **Languages:** TypeScript, Java (Spring), Python.
*   **DevOps:** Docker, Cloud Build, Terraform, GitHub Actions.
*   **Testing:** **Vitest** for robust quality assurance across front-end projects.

## 📂 Repository Roadmap
*   `infra-core`: VPC networking, Subnets, and IAM configurations.
*   `ai-agent-lab`: Python-based intelligent agents and AI workflows using Vertex AI.
*   `project-cloud`: Scalable architecture patterns for enterprise-grade projects.
*   `serverless-patterns`: High-performance deployments using Cloud Run and Cloud Functions.
